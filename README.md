# crafts-role-service

This project is a full-stack web application built with Spring Boot for the backend and React for the frontend. It includes role-based access control for User, Seller, and Admin roles, along with features like registration, login, and Swagger API documentation.


## Tech Stack

 # Backend
- Java + Spring Boot
- Spring Security (JWT-based Authentication)
- JPA 
- MySQL 
- Swagger (OpenAPI 3)
- Enum-based Role Management

 # Frontend
- React (with Hooks)
- Axios (for HTTP calls)
- React Router (for routing)
- Form validation (e.g., using Formik or basic validation)

---

## Features

- User Registration & Login
- Role-based access: User, Seller, Admin
- Secure API with Spring Security and JWT
- Password encryption using BCrypt
- Swagger UI for API testing
- Enum usage for roles/permissions
- React frontend to interact with APIs
